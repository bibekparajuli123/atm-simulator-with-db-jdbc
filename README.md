# ATM Simulator with JDBC

A console-based ATM Management System built using Java, JDBC, MySQL, and Maven.

## Features

* Account Registration
* User Login
* Check Balance
* Deposit Money
* Withdraw Money
* View Transaction History

## Tech Stack

* Java
* JDBC
* MySQL
* Maven
* IntelliJ IDEA

## Database Tables

* `accounts`
* `transactions`

## How to Run

1. Create the MySQL database.
2. Update database credentials in `DBConnection.java`.
3. Run `Main.java`.
